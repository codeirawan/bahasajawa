# Basa Jawa SD 📜

Aplikasi gladhen (latihan) Bahasa Jawa interaktif untuk siswa Kelas 1 SD, berbasis web statis.

## Fitur

- **50 soal pilihan ganda** — diambil dari Wulangan 4 (Tembang Dolanan) dan Gladhen Sumatif Pungkasan Semester
- **3 kelompok soal**: Wulangan 1-2, Wulangan 3-4, dan Sumatif
- **Sistem skor real-time** — bener, salah, streak, nomor soal
- **Katrangan (pembahasan)** per soal
- **Tab Materi** — ringkasan materi: Tembang Dolanan, Crita Fabel, Ejaan, Kosakata Kewan, Tembang Prau Layar
- **Desain batik-inspired** — hijau natural dengan aksen amber, font Outfit + Playfair Display

## Tech Stack

- Pure HTML / CSS / JavaScript (no framework, no build step)
- Hosted on [Vercel](https://vercel.com)
